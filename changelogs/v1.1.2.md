# v1.1.2

## 新增

- 新增 NapCat / 容器运行时兼容性预检，启动前检查 rootfs、native runtime、proot smoke、外部存储可读性与通知权限。
- 新增运行时兼容性分类与前台服务启动失败分类，便于区分权限、安全策略、Android 12+ 后台启动限制和通用服务启动失败。
- 新增 `RuntimeCompatibilityProbe` 单元测试、运行时桥接合同测试、NapCat 脚本合同测试和 Manifest runtime 合同覆盖。

## 变更

- NapCat 启动脚本将 `/sdcard`、`/storage/emulated/0` 改为可读时才加入 optional bind，避免低版本或厂商 ROM 权限差异导致启动失败。
- `ContainerBridgeService` 在启动 NapCat 前执行 runtime compatibility preflight；blocking issue 直接阻断并更新错误状态，non-blocking warning 通过进度信息展示。
- CI 依赖关系调整为 app tests 与 module boundary checks 并行依赖 tooling，architecture / assemble 在前置验证后运行。
- Gradle 默认启用 configuration cache、build cache 和 parallel execution，并恢复 Kotlin incremental。
- 版本源更新为 `versionName = "1.1.2"`、`versionCode = 83`。

## 修复

- 修复 NapCat 在外部存储不可读时仍强制 bind `/sdcard` / `/storage/emulated/0` 可能导致 proot 启动失败的问题。
- 修复运行时服务启动失败日志过于泛化，无法直接定位权限、安全策略或前台服务后台启动限制的问题。
- 修复 CI 中 app tests 被 architecture / assemble 串行阻塞导致验证反馈过慢的问题。
