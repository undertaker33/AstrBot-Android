# v1.0.2

## 新增

- 补齐插件 Host API 异步桥、权限校验和审计底座。
- 新增插件宿主网络请求代理，插件可通过 `hostApi.fetch` / `hostApi.network.request` 使用宿主网络能力。
- 新增 Provider / Model 只读查询能力，插件可读取宿主 provider 与模型信息。
- 新增当前会话消息发送和当前会话历史只读查询能力。

## 修复

- 补齐插件 Host API 的 Hilt wiring、QuickJS callback 生命周期和权限合同测试。
- 补齐中文翻译，收口 `modulePluginCheck` 中既有 MissingTranslation 风险。
- 保持当前会话发送能力受会话 guard 约束，避免插件绕过宿主授权向任意会话发送。
