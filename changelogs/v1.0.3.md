# v1.0.3

## 新增

- 新增插件直接 LLM 调用能力，支持 `hostApi.callLlm` / `hostApi.llm.generate` 走宿主受控调用。
- 新增宿主上下文压缩能力，插件可调用 `hostApi.context.compress`。
- 新增插件定时任务回调，Cron 可唤醒 Plugin V2 scheduled handler。
- 新增插件流式输出能力，App Chat 支持可编辑流，QQ 侧提供关闭时最终消息 fallback。
- 新增富消息链能力，支持文本、图片等消息段向 App Chat / QQ 映射。

## 修复

- 修复 scheduled task 回调、stream lifecycle、rich message fallback 与 context tool source 的边界合同。
- 补齐 Cron 与插件 scheduled handler 的集成测试，避免定时任务执行路径绕过 Plugin V2 runtime。
- 保持 `hostApi.callLlm` 默认绕过插件 LLM hooks，避免插件调用再次进入自身 hook 链。
