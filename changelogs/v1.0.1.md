# v1.0.1

## 新增

- 新增应用内更新能力，可检查新版本、下载 APK、弹出安装入口，并支持稍后提醒与忽略当前版本。
- 新增更新包安装所需的 FileProvider 配置和安装后清理入口。
- 新增备份时是否导出 API key 的选项，完整备份和模块备份可按用户选择处理密钥字段。
- 新增插件斜杠指令管理员权限开关，支持把插件命令限制为管理员可用。

## 修复

- 调整设置、资源、备份和配置页面的交互与文案，减少顶栏、占位和表单状态异常。
- 将 Compose 图标改为依赖官方 extended Material icons，移除项目内手写图标拷贝。
- 刷新 CI 工作流与生成产物 guard，避免 `artifacts/` 下生成文件被误提交。
