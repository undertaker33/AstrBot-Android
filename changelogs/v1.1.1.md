# v1.1.1

## 新增

- QQ 普通群消息公共历史沉淀上线，普通群入站消息会写入公共群 session，便于插件读取群维度上下文。
- 新增 QQ pseudo streaming 文本与附件分流能力，文本可继续分段发送，图片等非音频附件在文本流结束后单独发送。
- 新增 QQ streaming reply 附件分流回归测试，覆盖文本分段先于图片附件发送的行为。

## 变更

- `hostApi.conversation.history` 在 QQ 群场景优先映射到公共群历史，避免把 `group:<gid>:user:<uid>` 隔离会话误当作群公共历史真源。
- `hostApi.message.send` 和 stream 持久化会将插件外部 conversation id 解析到本地 repository session，再写入宿主会话。
- `AGENTS.md` 补充任务包事实边界、工作区保护、Host API 能力边界和 QQ session id / origin / OneBot target 区分规则。
- 版本源更新为 `versionName = "1.1.1"`、`versionCode = 82`。

## 修复

- 修复 QQ 群聊隔离场景下插件读取历史时只能看到 bot 私有隔离上下文的问题。
- 修复插件发送消息和 stream 写入在外部 conversation id 与本地 session id 不一致时可能写错会话的问题。
- 修复带附件的 pseudo streaming 回复不能同时保留文本分段体验和附件发送的问题。
