# v1.0.4

## 新增

- 新增插件 Agent 能力注册，支持 `hostApi.registerAgent`、`hostApi.agent.run` 和 handler 内 `event.agent.run(input)`。
- 新增受控 Agent LLM / tool loop，插件可在宿主权限边界内注册并运行 Agent。
- 新增 Filter 组合表达式，支持 `allOf`、`anyOf`、`not` 组合 AST。

## 修复

- 修复 Agent 注册后生产可达性，补齐 handler invocation 与 `agent.run(input)` wiring。
- 修复 Filter AST 与旧 `declaredFilters` 的兼容顺序，保留 builtin-before-custom 语义。
- 补齐 Agent、Filter、QuickJS capability 和 runtime loader 相关回归测试。
