# v1.1.0

## 新增

- 插件 V2 API 完整发布，补齐宿主网络代理、Provider 只读查询、当前会话消息发送、当前会话历史读取、直接 LLM 调用、上下文压缩、定时任务回调、流式输出、富消息链、Agent 能力注册和 Filter 组合表达式。
- 应用内更新能力上线，支持检测 GitHub Release、展示更新弹窗、下载 APK、安装跳转、清理下载文件，并补齐版本比较和安装入口保护。
- 插件 Agent 运行时上线，支持 `hostApi.registerAgent`、`hostApi.agent.run` 与事件内 `event.agent.run(input)`，并在宿主权限边界内执行受控 LLM / tool loop。
- 插件定时处理器上线，Cron runtime 可通过 Hilt 注入插件 V2 scheduled dispatch，支持插件注册和触发定时 handler。
- 插件富消息与流式输出上线，支持文本、图片、文件等消息段建模，以及流式 begin / append / end / error 输出生命周期。

## 变更

- 插件宿主能力统一收口到 Plugin V2 host API foundation，统一权限、审计、异步回调、QuickJS promise 桥接和 runtime loader wiring。
- Filter 表达式从旧的声明式过滤扩展为 AST 组合模型，支持 `allOf`、`anyOf`、`not` 与 builtin-before-custom 兼容语义。
- Resource Center 的上下文压缩工具源接入插件 V2 上下文压缩能力，保留当前资源治理入口。
- 版本源更新为 `versionName = "1.1.0"`、`versionCode = 81`。

## 修复

- 修复插件 Agent 注册后的生产可达性和 handler invocation wiring。
- 修复插件 LLM、上下文压缩、流式输出、富消息、定时任务、Agent 和 Filter 能力在 QuickJS capability 暴露与 runtime loader 中的覆盖缺口。
- 修复应用内更新相关边界测试、Manifest contract、下载模型和 release asset 检测路径。

- `:app:testDebugUnitTest` 通过。
- `clean assembleDebug` 通过。
- release / debug APK 已按既有 release 资产命名生成。
