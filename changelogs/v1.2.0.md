# v1.2.0

## 新增

- 新增地理围栏模块组，覆盖 API、data、impl、presentation、runtime 边界，并接入应用设置页与配置详情入口。
- 新增地理围栏 Room v24 存储模型、迁移合同、运行时注册/触发/执行链和启动期 reconciliation。
- 新增宿主内部地理围栏 active capability，支持在受控边界内创建、更新、启停和删除地理围栏规则。
- 新增地理围栏相关架构合同、数据库合同、UI 状态、权限提示和运行时单元测试覆盖。

## 变更

- CI 功能模块 gate 扩展为覆盖 Plugin、QQ、Geofence、Settings 和 Config，避免地理围栏跨模块入口只依赖本地手工验证。
- App 版本源更新为 `versionName = "1.2.0"`、`versionCode = 84`。
- 设置页、ConfigDetail、插件 active capability 工具源和 app 启动链接入地理围栏能力，同时保持 `hostApi.geofence.*` 不对外公开。
- Manifest 增加地理围栏运行所需的位置权限声明和非导出的 transition receiver。

## 修复

- 修复新增地理围栏模块未纳入 CI 模块检查时，Settings / Config / Plugin 入口回归只能依赖本地验收的问题。
- 修复地理围栏相关数据库 schema、迁移合同和应用单测 classpath 没有随模块组同步收口的问题。
