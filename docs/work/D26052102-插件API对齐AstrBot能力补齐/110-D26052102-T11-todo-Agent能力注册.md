## 目标

实现插件声明式 Agent 能力注册，让插件可以基于宿主 LLM、centralized tool registry 和已授权 ToolSource 运行受控 tool loop。

## 非目标

- Agent 不是新平台 adapter。
- 不开放 Web API 注册。
- 不允许插件绕过 ToolSource availability。
- 不允许插件读取 provider secret。
- 不实现无限递归、多 Agent 长期自治或后台常驻任务。

## 必须实现

1. JS API
   - 提供 `hostApi.registerAgent({ key, systemPrompt, tools, model, handler })`。
   - handler 可调用 `agent.run(input)`。
   - 不提供 AstrBot 风格别名。

2. Agent registry
   - Agent key 在同一 plugin 内唯一。
   - 编译到 V2 registry snapshot。
   - plugin unload 时清理 runtime agent state。

3. Tool allow policy
   - Agent 只能调用插件自身工具、host builtin tools、当前 config/persona 允许的 ToolSource。
   - MCP / Skill / Web Search / Active Capability 必须通过 `FutureToolSourceRegistry` availability。
   - 不允许通过 tool name 字符串绕过 reserved source kind。

4. LLM orchestration
   - 复用 `T06` 的 host LLM port。
   - 默认绕过插件 LLM hooks，避免 Agent run 递归触发同插件 hook。
   - 支持 tool call loop，限制 max tool calls、max depth、timeout、max tokens、cost guard。

5. 审计与失败
   - 记录 agent key、tool call count、provider/model、usage、duration、failureCode。
   - tool failure 可返回给 LLM 或中止，语义必须固定并测试。

## 必须补测试

- `PluginV2AgentRegistryTest`
  - 注册 Agent。
  - 重复 key 被拒绝或覆盖，语义固定。
  - unload 清理 runtime state。

- `PluginV2AgentRunTest`
  - fake LLM + fake tool loop 成功。
  - max tool calls 生效。
  - timeout 生效。
  - Agent 调用未授权 ToolSource 被拒绝。
  - Agent run 默认绕过插件 LLM hooks。

- `PluginV2AgentToolPolicyTest`
  - 只能调用 allowlist 内 tool。
  - reserved source kind 不能被插件伪造。
  - ToolSource unavailable 时拒绝。

- 插件可注册并运行受控 Agent。
- Agent 无法绕过 ToolSource availability、provider secret 或权限策略。
- 有明确 cost / recursion / timeout guard。
