## 实现摘要

- 新增 `PluginV2MessageSendApi`，暴露 `hostApi.message.send({ text, markdown, attachments, conversationId })`。
- API 只允许当前 event conversation scope；显式请求其他 conversation 会返回 structured scope violation。
- attachment URI 只接受 `plugin://package/` 和 `plugin://workspace/`。
- production wiring 按平台分流：App Chat 走 `ConversationRepositoryPort.appendMessage`；QQ / OneBot 走 `QqScheduledMessageSender.sendScheduledMessage`，发送成功后再落本地会话，发送失败返回 `qq_delivery_failed` 且不落本地消息。
- QuickJS callback 会把当前 event 的 `conversationId`、`platformAdapterType`、`messageType` 注入 Host API request context。
