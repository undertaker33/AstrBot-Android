## 目标

建立 Plugin V2 主动宿主 API 的统一底座：QuickJS event callback 可 `await hostApi.*`，Kotlin 侧通过 Hilt-owned facade 调用宿主 port，权限、审计、timeout、structured error 和 failure guard 语义统一。

## 已确认约束

- 不暴露 AstrBot 风格别名；只使用 ElymBot canonical host API 命名。
- 所有主动能力必须经宿主代理；插件不得直接持有网络客户端、数据库、provider secret 或 adapter socket。
- 不进入源码实现前不得写 Feedback、worker prompt 或 Git。

## 非目标

- 不实现具体 `fetch`、provider 查询、message send、history、LLM、cron、streaming、rich message、Agent 或 filter AST。
- 不修改 `docs/context/`；如实现后事实变化，收口标记 `Needs uth-docs scoped-sync`。
- 不新增依赖，不新增 service locator，不回退到 static API。

## 必须实现

1. 新增 V2 host API facade 合同
   - 定义 `PluginV2HostApiFacade`。
   - 定义 `PluginV2HostApiRequestContext`，至少包含 `pluginId`、`requestId`、`conversationId`、`platformAdapterType`、`permissionSnapshot`、`triggerMetadata`。
   - 定义统一返回模型，区分 success、permission denied、timeout、invalid payload、host unavailable、execution failed。

2. 新增权限策略
   - 定义 well-known permission id：`network_request`、`call_model`、`provider_read`、`send_message`、`conversation_read`、`schedule_manage`、`message_stream`、`rich_message_send`、`context_compress`、`agent_run`。
   - 校验顺序固定为 manifest 声明、用户授权、trigger whitelist、运行时策略。
   - 权限失败返回 structured error，不能抛宿主内部异常给 JS。

3. 新增审计日志
   - 记录 `pluginId`、`api`、`permissionId`、`conversationId`、`platformAdapterType`、`requestId`、`succeeded`、`failureCode`、`durationMs`。
   - 复用 `PluginRuntimeLogBus`，不要新增平行日志系统。

4. 新增 QuickJS 异步桥
   - JS 侧 `hostApi.*` 调用可被 `await`。
   - Kotlin 侧宿主调用在受控 dispatcher 中执行，支持 timeout 和 cancellation。
   - callback invocation 等待 Promise settle；rejection 写 plugin runtime log。
   - 若 QuickJS wrapper 无法直接创建原生 Promise，必须提供等价 thenable/polyfill，并用测试证明 `await` 能继续执行后续 handler 逻辑。

5. 保持生产 DI 边界
   - 生产对象由 Hilt module 提供。
   - 不新增 `PluginExecutionHostApi` static 热路径。
   - 不新增 global singleton allowlist 或 static repository usage allowlist。

## 必须补测试

- `PluginV2HostApiPermissionPolicyTest`
  - manifest 未声明时拒绝。
  - 用户未授权时拒绝。
  - trigger whitelist 不包含能力时拒绝。
  - 全部满足时允许。

- `PluginV2HostApiAsyncBridgeTest`
  - fake host API 可被 QuickJS handler `await`。
  - timeout 返回 structured error。
  - rejection 写 runtime log。
  - callback settle 后后续 JS 逻辑继续执行。

- `PluginV2HostApiAuditLoggerTest`
  - success 和 failure 均写入审计字段。
  - 不泄露 provider secret、raw exception stack 或内部 DAO 信息。

- architecture/source contract
  - 确认无新增 production static host API 热路径。
  - 确认 `app` 未手写 plugin runtime graph。
