- Scene：`uth-dev`
- Mode：`todo-breakdown`

- 执行方式：待用户决定；本轮不写 worker prompt，不实现代码。

## 目标

补齐 `ContextStrategyToolSourceProvider.invoke()`，让 `compress_context` 从显式未实现状态变为可用的宿主上下文压缩能力，并提供插件可调用的 `hostApi.context.compress`。

## 非目标

- 不新增文本转图或 HTML 渲染。
- 不修改 conversation 数据；压缩结果只作为返回值或 LLM pipeline 临时上下文。
- 不开放跨会话压缩。
- 不让插件自定义任意 system prompt 绕过安全策略。

## 允许修改范围

- `feature/plugin/runtime/src/main/java/com/elymbot/android/feature/plugin/runtime/toolsource/ContextStrategyToolSourceProvider.kt`
- `feature/plugin/runtime/src/main/java/com/elymbot/android/feature/plugin/runtime/**`
- `feature/plugin/api/src/main/java/**`
- `feature/plugin/runtime/src/test/java/**`
- `app/src/test/java/com/elymbot/android/runtime/plugin/toolsource/**`
- `app/src/test/java/com/elymbot/android/runtime/plugin/**`

## 必须实现

1. ToolSource invoke
   - `ContextStrategyToolSourceProvider.invoke()` 不再返回 `context_compress_not_implemented`。
   - 当 `contextLimitStrategy != "llm_compress"` 时保持 unavailable / capability denied 语义。
   - 输入包含 conversation/message window、maxTokens、目标语言或输出长度。

2. Host API
   - 提供 `hostApi.context.compress(request)`。
   - 使用 `context_compress` permission。
   - 只允许当前会话。

3. 压缩执行
   - 通过 `T06` 的 host LLM port 执行。
   - 使用固定宿主压缩 prompt。
   - 默认绕过插件 LLM hooks。
   - 输入消息来自 `T05` 的 history port，不直连 DB。

4. 输出模型
   - 返回 `summary`、`sourceMessageCount`、`truncated`、`usage`。
   - LLM 返回空文本、超时、provider 不可用时给 structured error。

5. 审计
   - 记录 conversation、source count、target tokens、provider/model、duration、failureCode。

## 必须补测试

- `ContextStrategyToolSourceProviderTest`
  - `llm_compress` 激活时暴露并可执行 `compress_context`。
  - 未激活时不可用。
  - fake LLM 返回摘要后 status 为 success。
  - fake LLM 失败映射 structured error。

- `PluginV2ContextCompressApiTest`
  - 当前会话压缩成功。
  - 未授权时拒绝。
  - 跨会话请求被拒绝。
  - 调用 host LLM 时绕过插件 LLM hooks。

## 完成判定

- `compress_context` 不再返回 `context_compress_not_implemented`。
- 插件和 ToolSource 两条入口共享同一宿主压缩实现。
- 不发生跨会话读取或 DB 直连。
