## 实现摘要

- 新增 `PluginV2ConversationHistoryApi`，暴露 `hostApi.conversation.history({ limit, beforeMessageId, includeAttachments, conversationId })`。
- API 只允许读取当前 event conversation；跨 conversation 请求返回 structured scope violation。
- limit 默认收敛并有上限；支持 `beforeMessageId` 截断。
- production wiring 通过 `ConversationRepositoryPort.session()` 读取当前会话历史，不让 plugin runtime 直连 Room / DAO。
- attachment refs 返回 host-safe URI；非 `plugin://` / `host://` 的内部路径会收敛为 `host://conversation-attachments/<id>`。
