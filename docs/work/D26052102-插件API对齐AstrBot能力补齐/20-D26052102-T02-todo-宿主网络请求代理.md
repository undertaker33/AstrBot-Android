## 目标

实现插件主动网络请求能力 `hostApi.fetch` / `hostApi.network.request`，所有请求都走宿主网络代理和权限策略，不给插件直接网络客户端。

## 非目标

- 不开放 Web API 注册。
- 不允许插件监听端口、暴露 HTTP endpoint 或启动本地 server。
- 不允许 `file`、`content`、`intent`、localhost、私有网段、Unix socket 或 Android content provider 访问。
- 不实现下载管理器大文件下载；本 Todo 只做小响应代理。

## 必须实现

1. JS API
   - 提供 `hostApi.fetch(request)`。
   - 提供 canonical 同义入口 `hostApi.network.request(request)`。
   - 不提供 AstrBot 风格别名。

2. 请求模型
   - 支持 `url`、`method`、`headers`、`bodyText`、`bodyBase64`、`timeoutMs`。
   - 默认 method 为 `GET`。
   - 只允许 `GET`、`POST`、`PUT`、`PATCH`、`DELETE`、`HEAD`。
   - header key/value 必须做长度和非法字符校验。

3. 宿主执行
   - 通过 `RuntimeNetworkTransport` 或现有 OkHttp 宿主路径执行。
   - 使用 `network_request` permission。
   - 支持 manifest domain allowlist。
   - 阻断 localhost、loopback、link-local、private IPv4/IPv6 和非 `http/https` scheme。

4. 响应模型
   - 返回 `status`、`headers`、`bodyText`、`bodyBase64`、`contentType`、`elapsedMs`。
   - 默认响应体上限 1 MB。
   - 超限返回 `network_response_too_large`。
   - 网络失败返回 structured error，不暴露 OkHttp 内部异常堆栈。

5. 运行时治理
   - 单插件并发数有限制。
   - 单请求 timeout 有上限。
   - 失败写审计日志和 plugin runtime log。

## 必须补测试

- `PluginV2HostNetworkApiTest`
  - 成功 GET 返回 status/header/body。
  - POST body 通过宿主 transport。
  - 非 `http/https` scheme 被拒绝。
  - localhost / 私有网段被拒绝。
  - domain 不在 allowlist 时被拒绝。
  - 响应体超过 1 MB 返回 `network_response_too_large`。
  - timeout 返回 structured error。

- `RuntimeNetworkModelsTest`
  - 如新增 plugin host network capability，覆盖 enum / timeout profile / JSON 映射。

- architecture contract
  - 确认 QuickJS bridge 没有直接创建 OkHttp client。
  - 确认插件 runtime 没有新增 Android network permission 绕过路径。
