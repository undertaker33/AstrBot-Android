## 目标

实现插件主动发送当前会话消息的 host API，覆盖 App Chat 与 QQ 的当前事件会话 follow-up 场景，并保持权限、平台边界和审计一致。

## 非目标

- 不开放任意目标会话群发。
- 不开放跨平台 adapter 注册。
- 不实现富消息链；富消息属于 `T10`。
- 不实现 streaming；streaming 属于 `T09`。
- 不允许插件直接操作 QQ socket、OneBot client 或 conversation DAO。

## 必须实现

1. JS API
   - 提供 `hostApi.message.send({ text, markdown, attachments })`。
   - 只使用 canonical API，不提供 AstrBot 风格别名。

2. 当前会话约束
   - 默认只允许当前 `PluginMessageEvent` / `PluginCommandEvent` / LLM hook event 对应会话。
   - 没有当前会话上下文时返回 `missing_session_scope` 或等价 structured error。
   - schedule 场景仅允许发送到该 schedule 绑定的 `conversationId`。

3. 宿主发送 port
   - App Chat 通过现有 conversation/chat runtime sender 或 follow-up sender 落地。
   - QQ 通过现有 QQ plugin dispatch service / OneBot 发送适配层落地。
   - plugin runtime 不直接依赖平台具体 implementation；必要时经 app-integration adapter 注入。

4. 权限与审计
   - 使用 `send_message` permission。
   - 审计记录目标 conversation、platform、message length、success/failure。
   - 发送失败返回 structured error。

5. 附件边界
   - 本 Todo 可支持现有 `PluginMessageEventResult.Attachment` 等简单附件。
   - 路径必须经 `plugin://package` / `plugin://workspace` resolver。
   - 不支持的附件类型返回明确错误或降级文本。

## 必须补测试

- `PluginV2MessageSendApiTest`
  - 当前 App Chat 会话发送成功。
  - 当前 QQ 会话发送成功。
  - 无当前会话上下文时拒绝。
  - 未授权时拒绝。
  - 指定非当前会话时拒绝。
  - schedule 绑定会话允许，非绑定会话拒绝。

- platform adapter tests
  - App Chat fake sender 收到 text/markdown。
  - QQ fake sender 收到 text。
  - 发送失败映射为 structured error。

- architecture contract
  - plugin runtime 不直接依赖 QQ implementation socket。
  - 不新增 DB 直连。

## 完成判定

- 插件可以在当前事件会话内主动发送一条宿主消息。
- 任意跨会话发送仍被拒绝。
- App Chat 与 QQ 均有可验证路径或明确 fake adapter 测试。
