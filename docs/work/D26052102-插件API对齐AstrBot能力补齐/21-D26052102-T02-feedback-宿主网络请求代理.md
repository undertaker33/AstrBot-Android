## 风险与回滚

- 关闭自动 redirect 会让需要跳转的插件请求拿到 3xx 响应，由插件或后续宿主逐跳策略处理；这是为了保住 allowlist / private host 边界。
- 回滚时删除 `PluginV2HostNetworkApi` wiring 和 QuickJS 暴露即可，但会失去 Phase B 网络代理能力。

## 后续

- 若需要支持 redirect，后续必须做逐跳 URL / host / IP / allowlist 重校验，而不是恢复底层自动跳转。
