## 实现

- 新增“编辑人格”二级 Route，目录编辑入口接线至详情页；二级页独立返回/保存且不属于全局底栏主 Route。
- 表单只呈现人格名称、最多三标签、固定高度系统提示词、上下文消息数和启用状态；保存统一规范化标签并校验名称与消息数。
- 面板稳定态限定为 `EXPANDED` / `COLLAPSED`，拖动 offset 只在手势期间存在，释放按阈值吸附；把手触控高度为 `48dp`。
- 展开/收起驱动封面可见高度与居中取景同步动画；详情和目录沉浸模式继续消费 portrait，列表模式消费 square，缺失 crop 使用中心默认值。
- Photo Picker 选择来源后只调用 T02 `stageImport`；纵向与方形步骤共享同一 draft 但分别维护 crop spec，方形不从纵向结果二次裁切；退出/取消 discard，commit 失败保留旧封面并提示。
- Rework 1 移除首轮作为主缩放交互的滑杆，纵向和方形裁切区均改用 Compose 多点触控 `detectTransformGestures`：单指拖动更新中心、双指 pinch 更新 zoom；两步仍各自持有独立 `PersonaCropSpec`。
- 抽出 `applyCropGesture` 纯函数，将 pan 按 viewport 与当前 zoom 换算，中心钳制到 `0..1`、缩放钳制到 crop contract 的 `0.1..10`，非有限值或无效 viewport 保持原 spec，避免 NaN/Infinity 写入。
- Rework 2 修复最终 reviewer 的 Critical finding：详情 `EditorCover` 通过共享 `personaCoverRenderSpec` 消费已持久化 portrait center 与 zoom，并在展开/收起动态 viewport 高度变化时持续应用相同取景参数。
- Rework 2 修复 Important draft lifecycle finding：`Failure` 完整保留 draft、portrait/square crop 与错误信息；失败对话框可直接重试同一 commit，取消/dismiss/页面退出立即 discard；commit 成功前 repository profile 未更新，旧封面保持不变。
