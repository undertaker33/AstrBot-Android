## 目标

实现从人格卡编辑入口进入的二级详情页、五项真实业务字段、展开 / 收起两态拖动面板、动态封面取景，以及选图后的“纵向裁切 → 方形裁切”两步非破坏性流程。

## 全局约束

- 二级页标题为“编辑人格”，无全局底栏、搜索、筛选或更多菜单。
- 业务字段只包含人格名称、最多三标签、系统提示词、上下文消息数和启用状态。
- 不展示或编辑 `defaultProviderId`、`enabledTools`，不新增概念图中的不存在字段。
- 面板只能稳定停在 `EXPANDED` 或 `COLLAPSED`，不得保存任意中间高度。
- 图片选择 / 裁切只作用于 T02 的应用内 draft，绝不修改用户来源。

## 非目标

- 不改变目录双模式布局、Room schema 或备份格式。
- 不增加 Bot、Config、QQ、平台运行状态或 Role 能力。
- 不在本 Todo 引入第三方裁切库。

## 目标状态

```text
PersonaEditorPanelState = EXPANDED | COLLAPSED

PersonaCoverCropFlow
├─ IDLE
├─ PORTRAIT(draft, cropSpec)
├─ SQUARE(draft, portraitCrop, squareCrop)
├─ COMMITTING
└─ FAILURE(previousCoverPreserved)
```

面板拖动时可持有 transient offset；手势结束必须按距离阈值和速度方向吸附到两个 enum 状态之一。该 transient offset 不进入持久化 state。

## 实施步骤

1. 先写 state / gesture policy 测试：默认展开、越阈值吸附、未越阈值回弹、fling 方向、点击把手切换、返回键页面语义。
2. 实现 Persona 二级 Route 和 ViewModel draft；保存前校验名称、三标签规范化和上下文消息数，失败保持页面与面板状态。
3. 实现固定高度系统提示词输入框：内容未溢出不显示滚动反馈，溢出后只在输入框内部滚动；外层页面仍可滚动适配小屏。
4. 实现可拖动小横条：视觉本体克制，隐形触控高度至少 `48dp`，拖动跟手，释放后只吸附展开 / 收起。
5. 实现动态封面容器：展开时按顶部栏到面板顶的可见区取景，收起时按顶部栏到小横条的完整区取景，尺寸动画与图片重取景连续同步。
6. 接系统 Photo Picker / SAF 选择来源 URI，调用 T02 `stageImport`；读取失败或取消保持旧封面。
7. 实现纵向裁切步骤：拖动、双指缩放、重置居中，以模式一 / 详情纵向构图为预览。
8. 确认后进入方形裁切步骤：基于同一 draft 独立拖动 / 缩放，支持返回纵向步骤；不从纵向结果二次截取。
9. 两步确认后调用 T02 commit；任一步取消 / 页面退出调用 discard；commit 失败展示错误并保留旧封面。
10. 目录模式一 / 详情使用 portrait spec，模式二使用 square spec；缺失 spec 使用中心 `0.5,0.5` 与基础缩放 `1.0`。
