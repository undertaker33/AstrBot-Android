## Rework 1：目录裁切缩放与方卡合同

### Reviewer finding

- Critical：原目录渲染只把 `centerX / centerY` 映射为 `BiasAlignment`，未消费 `crop.zoom`，非默认裁切缩放没有进入最终图层。
- Important：原模式二固定 `260.dp` 高、图片区 `174.dp`，卡宽随屏幕变化，卡片和 square crop viewport 均不保证 1:1。

### 修复

- 新增 `PersonaCoverViewport`、`PersonaCoverRenderPolicy` 与纯函数；模式一明确选择 `portraitCrop`，模式二明确选择 `squareCrop`，中心和 zoom 由同一策略输出。
- 最终 `Image` 使用 `ContentScale.Crop + BiasAlignment` 处理中心，并通过 `graphicsLayer` 同时设置 `scaleX / scaleY = policy.scale`，非默认 zoom 实际改变最终显示比例。
- 模式二 `Surface` 改为 `aspectRatio(1f)`；双列继续等宽，右列继续下沉 `68.dp`，内部图片区和信息区按固定权重分配，名称 / 标签内容不改变卡片外部尺寸。
