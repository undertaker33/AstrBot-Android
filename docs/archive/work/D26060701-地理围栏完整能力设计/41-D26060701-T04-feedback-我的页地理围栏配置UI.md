### Rework 1：质量复核

Hilbert 提出：

- 缺 foreground/background 权限时仍可能把启用规则保存为 active。
- create/update/delete 等失败被 ViewModel 吞掉，UI 看起来像成功。
- stale/deleted bot target 仍可能通过 synthetic `BotProfile` 保存启用规则。

Lagrange 修复后：

- enabled 保存路径接收 `GeofencePermissionStatus`，权限不足写入 `PERMISSION_REQUIRED`；disabled 保存为 `PAUSED`。
- repository / runs 失败进入页面级错误状态，成功后清错。
- enabled 保存必须命中当前 `botProfiles` 中的真实 bot，stale target 阻断保存；synthetic bot 仅用于 disabled 草稿。
