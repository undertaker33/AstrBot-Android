## 实现摘要

- 新增并接入 `:feature:geofence:runtime`。
- 新增 runtime API ports：
  - `GeofenceRuntimeReconciliationPort`
  - `GeofenceRegistrationPort`
  - `GeofencePermissionStatusPort`
  - `GeofenceTransitionEnqueuePort`
- 新增 Android Geofencing runtime：
  - `GeofencingClient` adapter。
  - 可反解 `ruleId` / `regionId` 的 request id codec。
  - immutable geofence `PendingIntent`。
  - enter / exit / dwell transition 映射和 dwell delay。
  - 权限状态与 Play services 可用性检查。
  - 100 active region 容量治理。
- Manifest 新增定位权限和非导出 geofence transition receiver：
  - `ACCESS_COARSE_LOCATION`
  - `ACCESS_FINE_LOCATION`
  - `ACCESS_BACKGROUND_LOCATION`
  - `GeofenceTransitionReceiver`
- App 启动链新增 geofence runtime reconciliation。
- Receiver 只解析 transition 和 geofence ids 并 enqueue worker，不执行 LLM、网络或重数据库操作。
- Worker / processor 完成“接收并记录”：
  - 读取 rule / region / enabled config binding。
  - 写 execution start / complete / throttled / failed 记录。
  - 最小触发间隔节流。
  - 对 decoded stale trigger 的 missing rule / missing region / missing enabled binding 写 failed audit record。
  - invalid request id 走结构化 runtime audit log。
  - 不做 T03 action dispatch。
- 返修质量问题：
  - 不可注册状态和无 active regions 时通过 empty registration request 清理旧 geofence。
  - 新增 `listAllConfigBindings()`，registration / processor 不再依赖异步 `bindings.value` 快照。
  - registration reconciliation 使用 `Mutex` 串行化，避免并发旧快照覆盖新状态。
  - data store 仅允许明确的 stale-trigger failed audit codes 跳过 live reference checks，普通 execution record 仍要求 rule / region / binding 存活。
