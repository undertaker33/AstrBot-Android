## 目标

建立地理围栏完整能力的模块骨架、domain contract、Room 真源和 repository 基线，使后续 runtime、UI、Agent 工具和 Config 装载都能复用同一套规则、区域、绑定和执行记录模型。

## 已确认约束

- “我的-地理围栏配置”是唯一真源；ConfigDetail 只保存装载引用，不复制坐标、半径或动作定义。
- 生产依赖注入只能走 Hilt。
- 不把 geofence 塞入 Cron、Settings、Config 或 Plugin 既有 owner。
- `:feature:geofence:api` 不依赖 Android UI、Room、Google Play services、Maps SDK 或 Compose。

## 非目标

- 不注册真实 Android geofence。
- 不请求定位权限。
- 不实现地图选择器。
- 不实现 Agent prompt 创建。
- 不修改插件 Host API。
- 不修改 `docs/context/`；实现完成后若事实变化，收口标记 `Needs uth-docs scoped-sync`。

## 必须实现

1. 新增 Gradle 模块
   - `:feature:geofence:api`
   - `:feature:geofence:data`
   - `:feature:geofence:impl`
   - 暂不新增 runtime/presentation 的依赖实现；可以预留模块组任务。

2. 新增 domain model
   - `GeofenceRule`
   - `GeofenceRegion`
   - `ConfigGeofenceBinding`
   - `GeofenceExecutionRecord`
   - `GeofenceTransition`
   - `GeofenceActionType`
   - `GeofenceRuleStatus`

3. 新增 repository port
   - `GeofenceRuleRepositoryPort`
   - 暴露 `rules`、`bindings`、create/update/delete、pause/resume、region 管理、config binding 管理、execution record 写入和查询。
   - 所有写入入口必须校验 rule/region 基本字段。

4. 新增 Room 真源
   - `geofence_rules`
   - `geofence_regions`
   - `config_geofence_bindings`
   - `geofence_execution_records`
   - DB version 递增，补 migration 与 schema。

5. 新增 data store 与 mapper
   - `FeatureGeofenceRuleRepositoryStore`
   - `FeatureGeofenceRuleRepositoryPortAdapter`
   - rule + regions 聚合读取时保持排序稳定。
   - config binding 只保存 `configId`、`ruleId`、`enabled`、`sortIndex` 等引用字段。

6. 新增 app-integration Hilt binding
   - 绑定 repository port 到 data adapter。
   - 不让 `:app` 直接依赖 geofence data implementation。

7. 新增架构合同
   - `:feature:geofence:api` 不依赖 Android、Room、Google Play services、Maps SDK。
   - plugin API / runtime 主线不新增 `hostApi.geofence.*`。
   - `core/**` 不依赖 geofence feature。

## 必须补测试

- `GeofenceRuleValidationTest`
  - 拒绝空名称。
  - 拒绝无 trigger 的 rule。
  - 拒绝非法纬度、经度。
  - 拒绝低于硬下限的半径。
  - 允许低于推荐值但高于硬下限的半径，并保留可由 UI 提示的不稳定状态。

- `FeatureGeofenceRuleRepositoryStoreTest`
  - create/update/delete rule。
  - 一条 rule 下多个 region 按 `sortIndex` 输出。
  - config binding 不复制 rule 内容。
  - execution record 可按 rule 查询最近记录。

- architecture/source contract
  - geofence API boundary。
  - plugin API 不暴露 geofence。
  - app-integration 才接 data implementation。

## 完成判定

- 地理围栏规则、区域、Config 装载引用和执行记录都有稳定 Room 真源。
- 后续 runtime/UI/Agent Todo 能只依赖 geofence API port，不需要绕过 data store。
- 没有把地理围栏生产事实写进 Cron、ConfigProfile 内嵌字段或 Plugin Host API。
