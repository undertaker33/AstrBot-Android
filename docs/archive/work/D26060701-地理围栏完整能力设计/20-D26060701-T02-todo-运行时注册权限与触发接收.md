## 目标

接入 Android 地理围栏 runtime：声明定位权限，使用 Google Play services Geofencing API 注册 enabled + bound regions，接收 enter/exit/dwell transition，并把触发转为可审计的 WorkManager 执行入口。

## 已确认约束

- 首次创建或启用时才请求位置权限；不在 app 启动时主动申请。
- Android 11+ 后台定位需要引导到系统设置页。
- 后台触发存在延迟，不承诺秒级触发。
- 只注册 enabled 且存在 enabled Config binding 的规则。
- active geofence region 总数按 100 上限治理。

## 必须实现

1. 新增 runtime 模块
   - `:feature:geofence:runtime`
   - 依赖 geofence API、core logging、WorkManager、Hilt Worker、Google Play services location。
   - 不依赖 geofence presentation。

2. 新增 Manifest 权限和 receiver
   - `ACCESS_COARSE_LOCATION`
   - `ACCESS_FINE_LOCATION`
   - `ACCESS_BACKGROUND_LOCATION`
   - 非导出 `GeofenceTransitionReceiver`
   - 若需要 boot 后重注册，新增非导出 boot receiver 并声明 `RECEIVE_BOOT_COMPLETED`。

3. 新增 runtime ports
   - `GeofenceRuntimeReconciliationPort`
   - `GeofenceRegistrationPort`
   - `GeofencePermissionStatusPort`
   - `GeofenceTransitionEnqueuePort`

4. 新增 GeofencingClient adapter
   - 将 `GeofenceRule + GeofenceRegion` 映射为 Google geofence request。
   - request id 必须能反解 `ruleId` 与 `regionId`。
   - 使用 immutable `PendingIntent`。
   - 注册前检查 Play services 可用性和权限状态。
   - 超过 100 active region 时返回 `capacity_exceeded`，并写回 rule status。

5. 新增 reconciliation
   - app 启动时触发 `reconcileAsync(appScope)`。
   - rule 保存、暂停/恢复、binding 变化后可调用。
   - 权限不足时不注册，并把 status 标为 `permission_required`。
   - Play services 不可用时标为 `play_services_unavailable`。

6. 新增 receiver 与 worker
   - receiver 只解析 transition 和 geofence ids，然后 enqueue worker。
   - worker 读取 rule、region、binding，写 execution start record。
   - worker 做最小节流和状态复核。
   - worker 当前只完成“接收并记录”，动作分发交给 T03。

## 必须补测试

- `GeofenceRuntimeRegistrationTest`
  - enabled + binding 的 region 会注册。
  - 无 binding 不注册。
  - 权限不足不注册并标记 `permission_required`。
  - 超过 100 active region 时标记 `capacity_exceeded`。
  - Play services 不可用时标记 `play_services_unavailable`。

- `GeofenceTransitionReceiverTest`
  - receiver 不直接执行 LLM/网络。
  - receiver enqueue worker 时保留 transition 与 geofence ids。

- `GeofenceTransitionWorkerTest`
  - worker 解析 `ruleId/regionId`。
  - execution record start/complete 写入。
  - 最小触发间隔内返回 `throttled`。

- Manifest / architecture contract
  - 定位权限存在。
  - receiver 非导出。
  - runtime 不依赖 presentation。

## 完成判定

- 设备具备权限和 Play services 时，enabled + bound regions 可被注册。
- transition 可进入 worker，并形成执行记录。
- 权限不足、Play services 不可用、容量超限都有明确状态。
