## 目标

实现宿主内部 Agent 地理围栏能力：用户可用 prompt 创建/更新地理围栏；地理围栏 transition 可按规则执行消息、天气、新闻或通用 Agent prompt 动作，同时严格不向插件暴露 geofence API。

## 已确认约束

- 地理围栏不作为对外插件 API。
- Agent 创建工具是 host-owned internal tool source。
- Agent 不能绕过系统定位权限；缺权限时返回 structured error。
- 触发动作不能绕过目标 ConfigProfile 的 `webSearchEnabled` 策略。
- geofence-triggered turn 默认不暴露 geofence create/update 工具，避免递归。

## 非目标

- 不实现地图选择器。
- 不实现“我的”页 UI。
- 不实现 ConfigDetail 装载弹窗。
- 不扩大插件 Host API 权限。
- 不承诺真实设备 geofence 准实时触发。

## 必须实现

1. 新增 geofence trigger 表达
   - 建议扩展 `IngressTrigger.GEOFENCE_EVENT`。
   - raw payload 包含 `ruleId`、`ruleName`、`regionId`、`regionLabel`、`transition`、`latitude`、`longitude`、`radiusMeters`、`occurredAt`、`configId`。

2. 新增动作执行器
   - `send_message`：直接走宿主投递 port。
   - `agent_prompt`：构造 runtime ingress event 并走 `RuntimeLlmOrchestratorPort`。
   - `weather_forecast`：生成天气 prompt，并要求目标 config 的 web search 可用。
   - `news_digest`：生成新闻 prompt，并要求目标 config 的 web search 可用。
   - `host_capability`：仅支持 Design 明确允许的宿主能力；第一版可返回 `unsupported_action`，不做泛化执行。

3. 新增 Agent 创建工具
   - `create_geofence_rule`
   - `update_geofence_rule`
   - `list_geofence_rules`
   - `delete_geofence_rule`
   - `pause_geofence_rule`
   - `resume_geofence_rule`
   - schema 覆盖名称、位置、半径、trigger、动作、目标上下文和最小触发间隔。

4. prompt 创建语义
   - 支持明确经纬度。
   - 支持“使用当前位置”，但权限不足返回 `permission_required`。
   - 不支持纯地址猜测；缺坐标、当前位置或地图选择结果时返回 `missing_location`。
   - 创建成功但后台权限不足时保存规则并返回“未启用后台触发”状态。

5. 工具可见性
   - 普通用户消息中，根据 config 策略暴露 geofence create/list/update 等工具。
   - geofence-triggered turn 中隐藏 create/update/delete/pause/resume，避免自我递归。
   - 插件 runtime 不获得 `hostApi.geofence.*`。

6. 执行记录
   - 每次动作写 execution result。
   - 记录 `deliverySummary`，不记录完整敏感坐标到 runtime log。

## 必须补测试

- `GeofenceAgentToolSourceProviderTest`
  - prompt schema 可创建规则。
  - 缺位置返回 `missing_location`。
  - 使用当前位置但无权限返回 `permission_required`。
  - 创建成功但后台权限不足时 rule 保存为 `permission_required`。
  - geofence-triggered turn 不暴露 create/update/delete 工具。

- `GeofenceActionExecutorTest`
  - `send_message` 动作投递成功。
  - `agent_prompt` 构造 `GEOFENCE_EVENT` ingress。
  - `weather_forecast` 在 config 未启用 web search 时失败并给出明确 code。
  - `news_digest` prompt 包含 transition 和区域上下文。
  - execution record 写入成功/失败摘要。

- plugin boundary contract
  - `hostApi.geofence` 不存在。
  - plugin API 不引用 geofence domain model。

## 完成判定

- 用户可通过 Agent prompt 创建或管理 geofence rule。
- geofence transition 可触发宿主内部 Agent/消息动作。
- 插件没有获得任何 geofence API 或位置数据访问能力。
