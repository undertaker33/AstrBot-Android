## 目标

在手动创建模式中加入地图选择器作为主要位置选择体验，同时保留经纬度输入和“使用当前位置”兜底。完成定位权限 UX：前台定位、后台定位说明、权限不足时保存草稿但不注册 active geofence。

## 已确认约束

- 地图选择器为主体验。
- 地图 SDK key 不写入源码或任务文档。
- 地图不可用时不能阻断经纬度手动创建。
- 不在 app 启动时主动请求定位权限。
- 后台定位必须通过用户明确授权流程，不静默申请。

## 非目标

- 不实现 GeofencingClient 注册逻辑；注册由 T02。
- 不实现 Agent prompt 创建。
- 不实现 ConfigDetail 装载。
- 不实现反向地理编码；地址标签第一版可手填。

## 允许修改范围

- `app/build.gradle.kts`
- `app/src/main/AndroidManifest.xml`
- `feature/geofence/presentation/**`

- `feature/geofence/api/**`

- `app/src/test/java/com/elymbot/android/ui/settings/**`
- `app/src/androidTest/java/com/elymbot/android/ui/**`

## 必须实现

1. 新增地图依赖与配置
   - Maps SDK / Maps Compose 依赖只进入 presentation 或 app 所需边界。
   - API key 通过 manifest placeholder、`local.properties` 或安全配置注入。
   - 缺 key 时 UI 自动进入经纬度兜底模式。

2. 新增地图选择组件
   - 展示选中圆心。
   - 点击地图更新圆心。
   - 显示圆形半径覆盖层。
   - 半径 slider 与数字输入同步。
   - 经纬度字段与地图点位同步。

3. 新增当前位置入口
   - 点击“使用当前位置”时请求前台定位权限。
   - 获取当前位置成功后更新圆心。
   - 失败时显示错误，不写入空坐标。

4. 新增后台定位 UX
   - 用户启用规则或保存为 active 时，如果需要后台触发，显示用途说明。
   - Android 11+ 引导到系统设置授权后台定位。
   - 用户拒绝时允许保存，但 rule status 显示 `permission_required`。

5. 地图兜底
   - 地图 SDK 不可用、无 key、加载失败时仍显示经纬度/半径输入。
   - 兜底状态在 UI 上可见，但不作为保存失败原因。

## 必须补测试

- `GeofenceMapSelectorStateTest`
  - 点击地图更新经纬度。
  - 半径 slider 与数字输入同步。
  - 缺地图 key 时进入 fallback。

- `GeofenceLocationPermissionUiTest`
  - 未授权时点击“使用当前位置”触发前台定位请求状态。
  - 后台定位不足时 active 保存显示 `permission_required`。
  - 拒绝权限不丢失表单草稿。

- UI smoke
  - 地图选择器可打开。
  - 经纬度 fallback 可保存草稿。

## 完成判定

- 手动创建模式优先提供地图点选和半径可视化。
- 地图不可用时经纬度/当前位置兜底仍可使用。
- 前台/后台定位权限 UX 明确，且不在启动时主动申请权限。
