## 目标

在“我的”页新增“地理围栏配置”入口，并实现地理围栏二级页面的基础 UI：全局/二级顶栏、分页列表、右下角 FAB、创建/编辑卡片、运行记录弹窗和经纬度/半径兜底输入。

## 已确认约束

- 二级页面参考 Cron Jobs 页面。
- 一页展示两项。
- 右下角 `+` 打开卡片进行配置。
- 地图选择器由 T05 增强，本 Todo 必须先提供经纬度/当前位置兜底路径。
- UI 不直接访问 DAO，必须通过 geofence presentation controller / ViewModel / API port。

## 非目标

- 不实现 Maps Compose 地图选择器。
- 不实现真实 GeofencingClient 注册。
- 不实现 Agent prompt 创建。
- 不实现 ConfigDetail 装载弹窗。
- 不修改插件 API。

## 必须实现

1. 新增 presentation 模块
   - `:feature:geofence:presentation`
   - Compose + Hilt。
   - 只依赖 geofence API、bot/config/provider/persona/conversation 必要 API 和 core UI。

2. 新增“我的”页入口
   - `MeEntryKind.Geofence`
   - 标题 `地理围栏配置`
   - subtitle 说明可管理位置触发规则。
   - route 打开 `AppDestination.GeofenceRules`。

3. 新增导航 route
   - `geofence-rules`
   - 接入 `GeofenceRulesScreen(onBack = ...)`。
   - 使用二级顶栏模式。

4. 新增列表页面
   - 一页两项。
   - 展示空状态。
   - 支持上一页、下一页、跳页。
   - 卡片展示名称、区域摘要、trigger、动作、状态、最近触发。
   - 卡片支持编辑、暂停/恢复、删除、运行记录。

5. 新增创建/编辑卡片
   - 基础信息：名称、描述、启用。
   - 位置：区域列表、经纬度、半径、地址标签。
   - 触发：进入、离开、停留、停留延迟。
   - 动作：action type、action prompt。
   - 目标：平台、conversation、bot、config、persona、provider。
   - 节流：最小触发间隔。
   - 权限状态：权限不足时显示引导入口，不阻断保存草稿。

6. 新增运行记录弹窗
   - 最近 10 条。
   - 显示 transition、状态、时间、错误 code、摘要。

## 必须补测试
