## 完成内容

- 新增 Maps Compose 地图选择器能力，使用 `com.google.maps.android:maps-compose:8.3.0` 与 `androidx.activity:activity-compose:1.9.1`。
- 地图 API key 通过 `MAPS_API_KEY` 的 local properties、Gradle 属性或环境变量进入 manifest placeholder；源码和任务文档不保存真实 key。
- 缺 key、SDK 不可用或地图加载失败时进入经纬度/半径兜底，不阻断手动创建。
- 地图可用时显示圆心 marker 和半径 circle；点击地图同步经纬度；半径 slider 与数字输入同步。
- 新建规则且坐标为空时仍展示地图，以临时默认视角作为 camera center，不把默认点写入 draft；用户点选后才产生 selection 并同步经纬度。
- 地图加载使用 `onMapLoaded` 与 12 秒超时状态；超时进入 `LOAD_FAILED` fallback，且不清空用户已填写的手动坐标。
- 新增“使用当前位置”入口，点击后走前台定位权限请求状态；定位成功写入圆心，失败显示错误且不写入空坐标。
- 新增后台定位说明与设置入口；不在启动时主动请求定位权限，不静默申请后台定位。
- 权限不足但保存启用规则时，规则保存为 `PERMISSION_REQUIRED`，草稿内容不丢失。
