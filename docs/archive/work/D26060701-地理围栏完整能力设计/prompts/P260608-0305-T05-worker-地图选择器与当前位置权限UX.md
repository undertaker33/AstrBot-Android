## 目标

实现 T05：在手动创建/编辑地理围栏规则时提供地图选择器作为主要位置选择体验，同时保留经纬度输入和“使用当前位置”兜底。完成前台定位、后台定位说明和权限不足保存语义。

必须满足：

- 地图选择器为主体验。
- 地图不可用、无 key 或加载失败时，经纬度/半径输入仍可使用。
- 点击“使用当前位置”才请求前台定位权限；不要在 app 启动或进入页面时主动请求定位权限。
- 后台定位必须经过用户明确操作和用途说明；Android 11+ 走系统设置引导，不静默申请。
- 用户拒绝权限时不得丢失表单草稿；启用规则保存时应显示/保存为 `permission_required`，不得伪装成 active。

## 必须实现细节

### 1. Maps Compose 依赖与 API key 配置

- 在合适模块加入 Maps Compose 依赖。优先放在 `:feature:geofence:presentation`，除非架构或编译要求必须放在 app。
- 如果使用 `com.google.maps.android:maps-compose`，不要再无理由显式添加 `play-services-maps`。
- API key 不得写入源码、文档、测试或资源默认值。
- 支持从本地配置读取，例如：
  - `local.properties` 中的 `MAPS_API_KEY`；
  - Gradle property `MAPS_API_KEY`；
  - 环境变量 `MAPS_API_KEY`。
- manifest placeholder 默认允许为空；空 key 时 UI 必须走 fallback，不应崩溃。
- 如果需要给 UI 判断 key 是否存在，优先通过 geofence API port + Android adapter 读取 manifest metadata 或安全配置，不要让 presentation 直接依赖 app `BuildConfig`。
- 增加架构或单测，防止 API key 字符串被写入源码中的默认值。

### 2. Map selector state

新增可单测的状态/模型，建议命名可调整：

- `GeofenceMapSelectorState`
- `GeofenceMapSelection`
- `GeofenceMapAvailability`

必须覆盖：

- 当前圆心 latitude / longitude。
- 当前 radiusMeters。
- addressLabel。
- map availability：`AVAILABLE`、`MISSING_API_KEY`、`SDK_UNAVAILABLE`、`LOAD_FAILED`。
- 点击地图更新圆心。
- 半径 slider 与数字输入同步。
- 经纬度字段与地图点位同步。
- 不合法经纬度/半径不写入有效选择，保留字段错误。

### 3. Compose 地图组件

在 `GeofenceRulesScreen` 的创建/编辑表单“位置”分组中接入地图选择器：

- 有 key 且 SDK 可用时显示地图。
- 地图上显示选中圆心 marker。
- 地图上显示半径 circle。
- 点击地图更新圆心，并同步经纬度字段。
- 半径 slider 和数字输入双向同步。
- 地图加载失败时切换为 fallback 文案和经纬度/半径输入，不阻断保存。
- 设置稳定尺寸，避免地图/表单切换时导致弹窗布局跳动。
- 保留 test tags：
  - `geofence-map-selector`
  - `geofence-map-fallback`
  - `geofence-map-radius-slider`
  - `geofence-use-current-location`
  - 继续保留 T04 已有 `geofence-create-latitude`、`geofence-create-longitude`、`geofence-create-radius`。

### 4. 当前位置 port 与权限请求 UX

如果 API 还没有当前位置 port，新增：

- `GeofenceCurrentLocationPort`
- 返回模型包含 latitude、longitude、accuracyMeters、capturedAtMillis。
- runtime/app adapter 可使用 `FusedLocationProviderClient`，但 presentation 只依赖 API port。

UI 行为：

- 点击“使用当前位置”时，若前台定位未授权，触发 Compose permission launcher 请求 `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION`。
- 授权后调用当前位置 port；成功则更新圆心和字段。
- 失败时显示错误，不写入空坐标，不清空表单草稿。
- 如果用户拒绝前台权限，保留草稿并显示权限说明。
- 不在 `LaunchedEffect`、页面进入、ViewModel init 或 app 启动时主动请求权限。

### 5. 后台定位 UX

- 当用户保存 enabled 规则且 `backgroundGranted=false` 时：
  - UI 显示后台定位用途说明。
  - Android 11+ 引导用户进入系统设置页授权后台定位；不要静默申请。
  - 如果用户继续保存或拒绝授权，规则仍可保存，但状态应为 `PERMISSION_REQUIRED`。
- 与 T04 返修保持一致：`GeofenceRuleEditorDraft.toRule(... permissionStatus)` 已根据权限不足写入 `PERMISSION_REQUIRED`，不要回退为 `ACTIVE`。
- 可新增 `GeofenceLocationPermissionUiState`，保证拒绝权限不丢失 draft。

### 6. 架构边界

- `:feature:geofence:presentation` 不得直接依赖 `:feature:geofence:runtime`、`:feature:geofence:data`、Room DAO/entity、app-integration implementation。
- Android runtime adapter 通过 Hilt 绑定到 API port。
- app shell 只处理 manifest placeholder、必要 Hilt module、ActivityResult/intent 启动边界。
- 不新增 static registry、service locator 或手写 runtime subgraph。

### S2-1：新建规则空坐标时地图不是主体验，无法直接地图点选

问题证据：

- `GeofenceRuleEditorDraft.fromTargetContext()` 不初始化经纬度。
- `GeofenceMapSelectorState.shouldShowMap` 要求 `selection != null`。
- `GeofenceRulesScreen` 只在 `shouldShowMap` 为真时渲染 `GoogleMap`，否则显示 fallback。

违反要求：

- T05 要求地图选择器为主体验，并且点击地图更新圆心。
- 新建规则初始空坐标时，用户应该仍能看到地图并通过地图点击选择圆心。

修复要求：

- map availability 为 `AVAILABLE` 时，即使 draft 还没有有效坐标，也应展示地图。
- 为空坐标提供一个明确的临时相机中心或默认视图中心，但不要把这个默认中心误写成有效规则坐标。
- 用户点击地图后才写入有效 latitude/longitude，并同步经纬度字段。
- UI 必须清楚表达“点击地图选择圆心”状态。
- 增加单测覆盖：空坐标 + map available 时 `shouldShowMap` 为真；点击地图后产生有效 selection。

### S2-2：`LOAD_FAILED` 没有实际运行时进入路径

问题证据：

- `AndroidGeofenceMapAvailabilityPort.currentAvailability()` 只返回 `MISSING_API_KEY`、`SDK_UNAVAILABLE` 或 `AVAILABLE`。
- UI 没有 `onMapLoaded` / failure callback / 超时逻辑把真实加载失败切到 fallback。

违反要求：

- T05 要求地图 SDK 不可用、无 key、加载失败时仍显示经纬度/半径输入。

修复要求：

- 给 Compose 地图组件增加真实运行时 `LOAD_FAILED` 入口。可接受方案：
  - 使用 `onMapLoaded` + 超时状态：若 map available 但在合理时间内未 loaded，则将当前 UI map availability 降级为 `LOAD_FAILED`；
  - 或使用 Maps Compose 可用的加载失败/异常状态入口，如果当前版本提供。
- `LOAD_FAILED` 后必须展示 fallback，并保留手动经纬度/半径输入与保存草稿能力。
- 不得因为地图加载失败清空 draft。
- 增加单测覆盖状态机或 UI state：available 未 loaded 超时进入 `LOAD_FAILED`；fallback 不阻断手动字段。
