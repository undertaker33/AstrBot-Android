## 任务目标

接入 Android 地理围栏 runtime：声明定位权限，使用 Google Play services `GeofencingClient` 注册 enabled + bound regions，接收 enter/exit/dwell transition，并把触发转为可审计的 WorkManager 执行入口。

完成后应满足：

- 设备具备权限和 Play services 时，enabled + bound regions 可被注册。
- transition 可进入 worker，并形成 execution record。
- 权限不足、Play services 不可用、容量超限都有明确状态。

## 必须实现

1. 新增 runtime 模块
   - 注册 `:feature:geofence:runtime`。
   - 依赖 geofence API、core logging、WorkManager、Hilt Worker、Google Play services location。
   - 不依赖 geofence presentation。
   - 不引入 Maps SDK；地图选择器属于后续 T05。

2. Manifest 权限和 receiver
   - 声明：
     - `ACCESS_COARSE_LOCATION`
     - `ACCESS_FINE_LOCATION`
     - `ACCESS_BACKGROUND_LOCATION`
   - 新增非导出 `GeofenceTransitionReceiver`。
   - 若需要 boot 后重注册，新增非导出 boot receiver 并声明 `RECEIVE_BOOT_COMPLETED`；若不实现 boot receiver，在返回中说明理由和后续补点。

3. 新增/完善 runtime ports
   - `GeofenceRuntimeReconciliationPort`
   - `GeofenceRegistrationPort`
   - `GeofencePermissionStatusPort`
   - `GeofenceTransitionEnqueuePort`
   - API port 放在 `feature/geofence/api/**`，实现放在 `feature/geofence/runtime/**` 或 app-integration wiring 中。

4. GeofencingClient adapter
   - 将 `GeofenceRule + GeofenceRegion` 映射为 Google geofence request。
   - request id 必须能反解 `ruleId` 与 `regionId`；建议使用可测试的编码/解码函数并覆盖单测。
   - transition types 必须按 rule 的 enter/exit/dwell 开关映射。
   - dwell 需要带 `loiteringDelay` / dwell delay 语义；不要对未启用 dwell 的 rule 注册 dwell transition。
   - 使用 immutable `PendingIntent`，必要时叠加 update current，但不得使用 mutable PendingIntent。
   - 注册前检查 Play services 可用性和权限状态。
   - 超过 100 active region 时返回 `capacity_exceeded`，并写回 rule status。

5. Reconciliation
   - app 启动时通过现有 startup chain 触发 `reconcileAsync(appScope)`。
   - rule 保存、暂停/恢复、binding 变化后应存在可调用入口；如果当前 UI/Agent 还没接入，至少让 repository/runtime wiring 提供这个入口，不在 T02 硬接 UI。
   - 只注册 enabled 且存在 enabled config binding 的 rule/region。
   - 权限不足时不注册，并把相关 rule status 标为 `permission_required`。
   - Play services 不可用时不注册，并标为 `play_services_unavailable`。
   - active region 超过 100 时不越界注册；被跳过或整体失败的 rule 必须有明确状态。

6. Receiver 与 worker
   - receiver 只解析 transition 和 geofence ids，然后 enqueue `GeofenceTransitionWorker`。
   - receiver 中不执行 LLM、网络请求或重数据库操作。
   - worker 读取 rule、region、binding，写 execution start record。
   - worker 做最小节流和状态复核。
   - worker 当前只完成“接收并记录”，动作分发交给 T03。
   - execution record 应记录 complete/throttled/failed 等结果；日志不要输出完整经纬度。
