完成应用内更新功能：启动时检测 GitHub Release latest APK，按当前 build track 选择 debug/release 包，强制用户在更新、暂不更新、忽略版本中选择，复用下载主线展示进度，下载完成后拉起系统安装器，并在安装完成后清理 APK。

## 必须实现

1. Release 检测
   - 使用 `RuntimeNetworkTransport` 请求 `https://api.github.com/repos/undertaker33/ElymBot/releases/latest`。
   - 读取 `tag_name`、`name`、`html_url`、`draft`、`prerelease`、`assets[]`。
   - 检测失败只写日志，不弹阻断失败提示。
   - 当前版本等于或高于 latest tag 时不提示。

2. APK asset 选择
   - 只接受 `state == uploaded`、`.apk`、HTTPS `browser_download_url`。
   - debug build 只选择文件名包含 `debug` 的 APK。
   - release build 只选择文件名包含 `release` 且不包含 `debug` 的 APK。
   - release track 缺失时不允许退到任意非 debug APK。

3. 提示抑制
   - `暂不更新` 必须保存 `snoozedTagName + remindAfterEpochMillis`，只对当前 release tag 生效。
   - `忽略此版本` 保存 `ignoredTagName`，只对当前 release tag 生效。
   - latest tag 变化时，旧 snooze 和 ignore 不得压住新版本。

4. 弹窗状态
   - 所有更新弹窗 `onDismissRequest = {}`。
   - 初始提示必须是 `更新`、`暂不更新`、`忽略此版本` 三选一。
   - 下载中显示进度条、速度、已下载/总大小。
   - 下载完成只显示安装动作。
   - 失败状态不得只有“关闭”；必须保留可执行决策出口，至少包含 `重试`、`暂不更新`、`忽略此版本`。
   - 插件 deep link 确认弹窗存在时，更新弹窗不得叠加显示。

5. 下载与安装
   - 新增或保留 `DownloadOwnerType.APP_UPDATE`。
   - 下载目标路径为 `filesDir/app-updates/<tag>/<assetName>`。
   - task key 为 `app-update:<tag>:<track>`。
   - 使用 `FileProvider` content URI + APK MIME + `FLAG_GRANT_READ_URI_PERMISSION` 拉起系统默认 APK 打开方式。
   - Manifest 声明 `REQUEST_INSTALL_PACKAGES`、非导出 `FileProvider`、`MY_PACKAGE_REPLACED` receiver。
   - 安装成功后通过 receiver 或下次启动清理 APK 与空目录。

6. Hilt / 边界
   - 不新增 static repository、global registry、service locator 或手写 app container。
   - `AppUpdateViewModel` 必须走 `@HiltViewModel`。
   - 新增 app update store 不得破坏 Strict Hilt 合同；如果保留 repository 私有 SharedPreferences wrapper，测试要覆盖无 production static bypass。

## 必须补测试

- `AppUpdatePolicyTest`
  - 解析 release JSON。
  - debug/release asset 严格选择。
  - release 缺失不 fallback。
  - tag-scoped snooze。
  - ignore 当前 tag 后，新 tag 仍可提示。
  - 版本比较和安装后清理判断。

- `RuntimeNetworkModelsTest`
  - 覆盖 `RuntimeNetworkCapability.APP_UPDATE`。
  - 覆盖 `RuntimeTimeoutProfile.APP_UPDATE`。

- `AndroidManifestRuntimeContractTest`
  - 覆盖 `REQUEST_INSTALL_PACKAGES`。
  - 覆盖 `${applicationId}.fileprovider`、`grantUriPermissions="true"`、`@xml/update_file_paths`。
  - 覆盖 `.update.AppUpdateCleanupReceiver` 与 `android.intent.action.MY_PACKAGE_REPLACED`。

- MainActivity / source contract
  - 覆盖 `checkForUpdateOnce()` 只在 Activity content 初始化后触发一次。
  - 覆盖 pending plugin deep link 存在时不显示 `AppUpdateDialogHost`。
  - 覆盖更新弹窗 host 接入 `AppUpdateViewModel`。
