## 实现摘要

- `ContainerBridgeService.handleStartBridge()` 在 `containerRuntimeInstaller.ensureInstalled()` 后、`containerRuntimeController.startNapCat()` 前执行 `RuntimeCompatibilityProbe.runPreflight()`。
- blocking 诊断调用 `bridgeStatePort.markError(compatibility.userMessage)`，写入 technical details，并停止后续 NapCat 启动。
- non-blocking 诊断写入 runtime logger，并通过 `updateProgress` 呈现降级 warning 后继续启动。
- `AndroidRuntimeBridgeController` 新增启动失败分类 helper，区分 `SecurityException`、Android 12+ foreground service background start restriction、foreground service failure 和普通 service start failure。
- `AndroidManifestRuntimeContractTest` 锁定 `FOREGROUND_SERVICE_DATA_SYNC` 与 `foregroundServiceType="dataSync"`。
