# D26060501-T02 NapCat 脚本条件绑定与启动降级 Todo Implementation Plan

> **For agentic workers:** Use `uth-sp-subagent-driven-development` or `uth-sp-executing-plans` only if the owning UTH scene chooses that execution mode. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `start_napcat.sh` tolerate unavailable external storage binds without blocking the base NapCat container startup path.

**Architecture:** Keep the change inside runtime scripts and their contract tests. The script should build optional bind arguments only after checking host paths, while preserving the existing proot smoke test and rootfs start flow.

**Tech Stack:** POSIX shell under `/system/bin/sh`, proot command assembly, existing Kotlin contract tests.

## 目标

把当前无条件绑定 `/sdcard` 与 `/storage/emulated/0` 的行为改为条件降级：

- 路径存在且可读时才加入 proot bind。
- 路径不可读或不存在时写入 runtime log warning。
- 外部存储 bind 被跳过不影响 rootfs / proot smoke test 和基础 NapCat 安装启动。
- 脚本合同测试能防止以后重新写回无条件 bind。

## 非目标

- 不改 Kotlin probe 接入；该工作在 T03。
- 不改 manifest 权限。
- 不新增 `MANAGE_EXTERNAL_STORAGE` 或旧读写存储权限。
- 不移动 rootfs、runtime assets 或 native binary。
- 不修改 upstream NapCat installer 内容。

## 必须实现

1. 条件 bind helper
   - 在 `start_napcat.sh` 中新增 helper，例如 `add_optional_bind_if_readable`
   - helper 检查 source path 存在且可读，满足条件才调用已有 `add_bind_arg`
   - 不满足时写入 `$LOG_FILE`，并继续执行

2. 移除无条件外部存储 bind
   - proot 主启动命令不得继续硬编码：
     - `-b /sdcard`
     - `-b /storage/emulated/0:/sdcard`
     - `-b /storage/emulated/0:/storage/emulated/0`
   - 应改为由条件 helper 生成的 bind 参数注入

3. 保持关键 smoke test
   - `start_napcat: running proot smoke test` 必须保留
   - smoke test 失败仍然 exit 5
   - 条件外部存储 bind 不能影响 smoke test 的基础判定

4. 合同测试
   - 断言脚本包含条件 bind helper
   - 断言脚本包含 external storage skipped warning
   - 断言脚本不再包含固定无条件 `/storage/emulated/0:/sdcard` bind
   - 断言 proot smoke test 仍存在
