## 问题

上一轮 Design-level 验收补跑完整 `:app:testDebugUnitTest` 时失败。失败原因是 T02 把 `:core:runtime-audio` 和 `:core:runtime-container` 作为 app 单测 runtime 分组字符串写入 `app/build.gradle.kts`，触发两个 architecture contract：

- `RuntimeAudioBoundaryContractTest.core_runtime_audio_module_must_be_registered_and_reported`
- `RuntimeContainerBoundaryContractTest.runtime_container_module_must_be_registered_reported_and_consumed`

这两个合同断言 app shell 不应直接包含 `:core:runtime-audio` / `:core:runtime-container`；runtime wiring 应由 `app-integration` 持有。

## 修复

- 从 `app/build.gradle.kts` 的 `appUnitTestRuntimeProjectGroups` / `core runtime` 分组中移除 `:core:runtime-audio` 和 `:core:runtime-container`。
- 保留 `:app-integration` 作为 app 单测 runtime classpath 的 app shell 分组入口。
- 不修改生产依赖、DI、Manifest、APK 导出、版本号或测试源码。

修复后 `rg -n 'core:runtime-audio|core:runtime-container' app\build.gradle.kts app-integration\build.gradle.kts settings.gradle.kts build.gradle.kts` 显示这两个模块只剩在以下允许位置：

- `settings.gradle.kts`
- 根 `build.gradle.kts` 的 architecture source roots / module group
- `app-integration/build.gradle.kts`
