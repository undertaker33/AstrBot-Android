## 风险与回退

- module group lazy wiring 依赖当前模块都能通过 plugin id 绑定 build task；如果后续新增非 Android/JVM module group，需要在 `configureModuleGroupBuildDependency` 中显式支持。
- app 单测 classpath 分组是行为等价整理；若后续继续收窄，应按分组逐步删除并运行完整单测，不要一次删除全域 runtime project。
- APK export finalizer 若远端 CI 行为异常，可回退到原 `afterEvaluate` 结构，但本地 `clean assembleDebug` 已证明 `exportDebugApkByBranch` 仍会执行。
