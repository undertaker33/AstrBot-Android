## 实现摘要

- 根 `gradle.properties` 默认启用 `org.gradle.configuration-cache=true`、`org.gradle.caching=true`、`org.gradle.parallel=true`。
- `build-logic/gradle.properties` 移除 `kotlin.incremental=false`，保留 `kotlin.compiler.execution.strategy=in-process`。
- CI 中 `app-tests` 改为 `needs: tooling`；`architecture-and-assemble` 改为等待 `tooling`、`module-boundary-checks`、`app-tests`，继续作为最终 `clean architectureCheck assembleDebug` gate。
- 默认 configuration cache 暴露出 `architectureSourceRootsReport` / `architectureDebtReport` 的 Gradle script object 捕获问题；已把两个报告任务改为 typed task，显式声明输入/输出并保留 `outputs.upToDateWhen { false }`。

## 风险与回退

- 若远端 CI 因 job 并行后资源竞争失败，回退 `.github/workflows/ci.yml` 的 `needs` 关系即可，不影响本地 Gradle 配置。
