# D26060301-T01 默认性能能力与 CI 解串 Todo Implementation Plan

> **For agentic workers:** Use `uth-sp-subagent-driven-development` or `uth-sp-executing-plans` only if the owning UTH scene chooses that execution mode. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable the low-risk Gradle performance defaults and remove unnecessary CI serialization without reducing validation coverage.

**Architecture:** This slice changes only repository build configuration and GitHub Actions job dependencies. It does not change source code, dependency versions, test suites, release outputs, or architecture report freshness.

**Tech Stack:** Gradle 9.4.1, Android Gradle Plugin 9.2.0, Kotlin 2.2.10, GitHub Actions.

## 目标

把 Design 中低风险、可独立验证的构建优化先落地：

- 根 `gradle.properties` 默认启用 Gradle configuration cache、build cache 和 parallel execution。
- `build-logic` 不再强制关闭 Kotlin incremental。
- CI 中 `app-tests` 不再等待 `architecture-and-assemble`，而是在 `tooling` 后与 module boundary checks 并行；`architecture-and-assemble` 保持最终 debug 构建 gate。

## 已确认约束

- 不修改业务源码、DI、Manifest、版本号、依赖版本或 release APK 导出目录。
- 不移除任何 CI job、Gradle 验证入口或测试命令。
- 不修改 `architectureSourceRootsReport` / `architectureDebtReport` 的 `outputs.upToDateWhen { false }` 行为。
- 不引入远程 build cache、Develocity 或第三方分析插件。
- 不执行 Git 写入。

## 非目标

- 不处理 `build.gradle.kts` 中的 `gradle.projectsEvaluated`。
- 不处理 `app/build.gradle.kts` 中的 `afterEvaluate`。
- 不收窄 `:app:testDebugUnitTest` 的手工 classpath / `-Xfriend-paths`。
- 不迁移 app 单测到 feature 模块。
- 不更新 `docs/context/`；实现完成后只标记是否需要 `uth-docs scoped-sync`。

## 允许修改范围

- `gradle.properties`
- `build-logic/gradle.properties`
- `.github/workflows/ci.yml`
- `build.gradle.kts`
- `docs/archive/work/D26060301-构建优化/11-D26060301-T01-feedback-默认性能能力与CI解串.md`
- `docs/current-state.md`

## 必须实现

1. 根 Gradle 性能开关
   - 在根 `gradle.properties` 增加 `org.gradle.configuration-cache=true`。
   - 增加 `org.gradle.caching=true`。
   - 增加 `org.gradle.parallel=true`。
   - 如验证发现 configuration cache 问题导致任务失败，只能临时增加 `org.gradle.configuration-cache.problems=warn`，并在 Feedback 记录原因。

2. build-logic 增量配置
   - 移除 `build-logic/gradle.properties` 中的 `kotlin.incremental=false`。
   - 保留 `kotlin.compiler.execution.strategy=in-process`，除非 `:build-logic:check` 明确证明它造成失败。

3. CI 依赖解串
   - `module-boundary-checks` 继续 `needs: tooling`。
   - `app-tests` 改为 `needs: tooling`。
   - `architecture-and-assemble` 改为等待 `tooling`、`module-boundary-checks`、`app-tests`，继续运行 `clean architectureCheck assembleDebug`。
   - 所有 job 的命令和覆盖面保持不变。

4. architecture report 配置缓存兼容
   - 如果默认 configuration cache 暴露 `architectureSourceRootsReport` / `architectureDebtReport` 的脚本对象捕获问题，必须修为 typed task。
   - 保持 `outputs.upToDateWhen { false }`，不缓存 architecture 报告产物。
   - 不把 `org.gradle.configuration-cache.problems=warn` 写成根默认配置。

## 执行步骤

- [x] **Step 1: 修改根 Gradle 性能开关**

在 `gradle.properties` 末尾加入：

```properties
org.gradle.configuration-cache=true
org.gradle.caching=true
org.gradle.parallel=true
```

- [x] **Step 2: 恢复 build-logic Kotlin incremental 默认策略**

把 `build-logic/gradle.properties` 改为：

```properties
kotlin.compiler.execution.strategy=in-process
```

- [x] **Step 3: 调整 CI job 依赖**

把 `.github/workflows/ci.yml` 中的依赖改为：

```yaml
  module-boundary-checks:
    needs: tooling

  architecture-and-assemble:
    needs:
      - tooling
      - module-boundary-checks
      - app-tests

  app-tests:
    needs: tooling
```

- [x] **Step 4: 修复 architecture report 配置缓存兼容**

将 `build.gradle.kts` 中两个 architecture report 任务改为 typed task：

```kotlin
tasks.register<ArchitectureSourceRootsReportTask>("architectureSourceRootsReport") {
    sourceRoots.set(architectureMainSourceRoots)
    projectDirectory.set(layout.projectDirectory)
    reportFile.set(layout.projectDirectory.file(architectureSourceRootsReportPath))
    outputs.upToDateWhen { false }
}

tasks.register<ArchitectureDebtReportTask>("architectureDebtReport") {
    sourceRoots.set(architectureMainSourceRoots)
    projectDirectory.set(layout.projectDirectory)
    singletonAllowlistFile.set(layout.projectDirectory.file(globalSingletonAllowlistPath))
    staticRepositoryAllowlistFile.set(layout.projectDirectory.file(staticRepositoryUsageAllowlistPath))
    reportFile.set(layout.projectDirectory.file(architectureDebtReportPath))
    outputs.upToDateWhen { false }
}
```

- [x] **Step 5: 运行验证**

执行：

```powershell
.\gradlew.bat :build-logic:check --console=plain --no-daemon --stacktrace
.\gradlew.bat :app:testDebugUnitTest --dry-run --configuration-cache --configuration-cache-problems=warn --console=plain --no-daemon --stacktrace
.\gradlew.bat architectureCheck --configuration-cache --console=plain --no-daemon --stacktrace
.\gradlew.bat clean assembleDebug --console=plain --no-daemon --stacktrace
```

预期：命令退出码为 0；没有 `warning` / `deprecated` / `exception` / `failed` 残留，或在 Feedback 中列明并等待用户 waiver。
