## 模块职责

本模块当前覆盖：

- `:feature:geofence:api`：地理围栏 domain model、repository port、运行时 port、权限 / 地图 / 当前定位 / 注册 / 触发 / action execution contract。
- `:feature:geofence:data`：Room-backed `FeatureGeofenceRuleRepositoryStore` 与 `FeatureGeofenceRuleRepositoryPortAdapter`，负责规则、区域、Config 绑定和执行记录持久化。
- `:feature:geofence:presentation`：我的页地理围栏配置、规则列表、编辑器、地图选择器、当前位置权限交互、run history 和 Hilt ViewModel。
- `:feature:geofence:runtime`：Google Play services geofence 注册、WorkManager transition enqueue、transition processor、action executor、运行时 reconciliation、权限 / Play services / 当前定位 adapter。
- `:feature:geofence:impl`：当前是 API + data 聚合壳，不是生产 owner。
- `feature/config/presentation/geofence`：ConfigDetail 内的规则绑定展示与编辑，消费 geofence API port，不直接接 DAO / data store。
- `app-integration` wiring：通过 Hilt 绑定 geofence repository、active capability facade 和 message delivery port。
- `app` 入口：Manifest 权限和 receiver、启动 reconciliation、`geofence-rules` navigation route、我的页入口和 ConfigDetail 跳转。

## 非职责

- 不把地理围栏规则字段嵌入 `ConfigProfile`；ConfigDetail 只维护 `config_geofence_bindings` 引用。
- 不把 Resource Center projection 复用为地理围栏绑定模型；`ConfigResourceProjection` 不应增长 geofence 专用字段。
- 不暴露 `hostApi.geofence.*` 或插件直连 geofence API；Agent 创建/管理规则只能走宿主内部 active capability。
- 不把真实设备、Google Play services、厂商 ROM、后台定位授权、地图渲染或真实 enter/exit/dwell transition 写成已覆盖。
- 不把 `feature/geofence/impl` 写成业务 owner。
- 不由 core 模块依赖 `feature/geofence`；core 只提供通用 runtime context / DB primitive。

- `:feature:geofence:impl`
- `:feature:geofence:presentation`

根 `build.gradle.kts` 当前：

- 将 `feature/geofence/api/src/main/java`、`data/src/main/java`、`impl/src/main/java`、`presentation/src/main/java`、`runtime/src/main/java` 纳入 `architectureMainSourceRoots`。
- 注册 `moduleGeofenceBuild` / `moduleGeofenceCheck`，覆盖 geofence API/data/impl/presentation/runtime。

依赖事实：

- `:feature:geofence:api` 不依赖 Android、Room、Google Play services、Maps SDK 或 Compose。
- `:feature:geofence:data` 依赖 `:core:db` 与 geofence API。
- `:feature:geofence:runtime` 依赖 core logging/runtime-context/runtime-llm、bot/config/conversation/geofence/plugin API、WorkManager、Hilt Worker、Google Play services location/base 与 coroutines play-services；不依赖 geofence presentation 或 Maps SDK。
- `:feature:geofence:presentation` 启用 Compose + Hilt，依赖 core runtime-context/ui、bot/config/conversation/provider API 与 geofence API。
- `app-integration` 以 `api(project(":feature:geofence:api"))` 暴露 geofence API，以 `implementation` 接入 geofence data/impl/runtime。
- `app/build.gradle.kts` 生产直接依赖 `:feature:geofence:presentation`；geofence data/runtime 通过 app-integration 和 Hilt 进入生产图。

## Runtime / registration / transition

运行时入口：

- `GeofenceRuntimeReconciliationPort.reconcileAsync(scope)`
- `GeofenceRegistrationPort.registerActiveGeofences()`
- `GeofenceTransitionEnqueuePort.enqueueTransition(...)`
- `GeofenceActionExecutorPort.execute(...)`

当前注册链路：

1. `RuntimeLaunchStartupChain.run()` 在 Cron reconciliation 后调用 `geofenceRuntimeReconciliationPort.reconcileAsync(appScope)`。
2. `GeofenceRegistrationCoordinator` 读取 enabled 且未 paused 的规则，并只注册存在 enabled Config 绑定的规则。
3. 注册前检查前台/后台定位权限、Google Play services 可用性和 active region 数量上限。
4. `AndroidGeofenceRegistrationBackend` 通过 `LocationServices.getGeofencingClient(context)` replace 当前 PendingIntent 下的 geofences。
5. 当前 PendingIntent 指向非导出 `GeofenceTransitionReceiver`。

当前触发链路：

- `GeofenceTransitionReceiver` 接收 Google Play services transition。
- `WorkManagerGeofenceTransitionEnqueuePort` enqueue `GeofenceTransitionWorker`。
- `GeofenceTransitionProcessor` decode request id，查找 rule / region / binding，执行最小触发间隔、trigger type、paused/enabled 等 preflight，再调用 `GeofenceActionExecutorPort`。
- 成功时更新 `lastTriggeredAt`；失败或节流会写执行记录。

## Action execution

当前 action type：

- `AGENT_PROMPT`
- `SEND_MESSAGE`
- `WEATHER_FORECAST`
- `NEWS_DIGEST`
- `HOST_CAPABILITY`

执行边界：

- `SEND_MESSAGE` 通过 `GeofenceMessageDeliveryPort` 投递，不绕过平台消息边界。
- `AGENT_PROMPT` 构造 `IngressTrigger.GEOFENCE_EVENT` 的 runtime turn，经 `RuntimeContextResolverPort` 和共享 LLM orchestrator 进入 provider / tool pipeline。
- `WEATHER_FORECAST` 与 `NEWS_DIGEST` 要求目标 ConfigProfile `webSearchEnabled` 为 true。
- `HOST_CAPABILITY` 当前返回 `unsupported_action`，不能写成已支持。
- 运行时 raw payload 中经纬度对 hook 可见数据做 redaction。

`RuntimeIngressContracts.kt` 当前新增 `IngressTrigger.GEOFENCE_EVENT`。修改 geofence action、ToolSource 或 prompt 组装时，要同时检查 runtime-context 与 plugin ToolSource 入口。

当前 ConfigDetail 关系：

- `feature/config/presentation/build.gradle.kts` 只依赖 `:feature:geofence:api`，不接 geofence data/runtime。
- `ConfigGeofenceBindingViewModel` 注入 `GeofenceRuleRepositoryPort` 与 `ConfigGeofenceBindingController`。
- `ConfigGeofenceBindingController` 更新 `config_geofence_bindings` 后触发 `GeofenceRuntimeReconciliationPort.reconcileNow()`。
- `ConfigProfile` 不嵌入 geofence coordinates、radius、action prompt 或 binding 字段。

## Plugin / Agent active capability

当前 Agent 管理地理围栏的入口在 `ActiveCapabilityToolSourceProvider`：

- `create_geofence_rule`
- `update_geofence_rule`
- `list_geofence_rules`
- `delete_geofence_rule`
- `pause_geofence_rule`
- `resume_geofence_rule`

这些工具通过 `GeofenceActiveCapabilityFacade` 调宿主实现。`GeofenceActiveCapabilityFacade` 明确标注 `INTERNAL_ACTIVE_CAPABILITY_ONLY`，并说明它不是 plugin Host API surface。

边界：

- 插件 API / runtime 不暴露 `hostApi.geofence.*`。
- geofence mutation 工具在 `IngressTrigger.GEOFENCE_EVENT` 下隐藏，避免地理围栏事件自我递归创建或修改规则。
- 缺省 facade 为 `DisabledGeofenceActiveCapabilityFacade`，未 wiring 时返回 `geofence_unavailable`。

## Backup / resource / settings 关系

- 地理围栏当前数据表不在 App backup 支持范围内。
- 不得把 `geofence_rules`、`geofence_regions`、`config_geofence_bindings`、`geofence_execution_records` 写成已支持导出/恢复。
- Resource Center projection 不承载 geofence binding。
- Settings presentation 只提供入口；规则 owner 是 geofence presentation / data / runtime。
